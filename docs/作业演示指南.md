# 信息安全课程：运行与截图指南

## 作品名称

《基于 AI 的智能反诈与钓鱼信息检测系统》

网页名称：辨信 · 反诈安全助手。

## 本次实际完成范围

完成 Python 网页原型，支持文本输入、本地风险规则、网址静态分析、带来源的本地知识检索、DeepSeek 工具调用 Agent、风险依据展示、报告导出及失败提示。

不包含手机应用、真实钓鱼网站访问、附件杀毒、实时诈骗数据库、自动举报、截图 OCR、向量数据库和公网部署。不要把这些写成已完成。

## 运行

1. 双击项目的 `start.bat`，保留运行终端。
2. 浏览器打开 `http://127.0.0.1:8503`。
3. 默认本地检查，不需要调用模型；Agent 模式要先检查脱敏预览并确认外部发送。
4. 默认进入“安全总览”，点击“新建检测”或侧栏“智能检测”。侧栏“分析设置与隐私”切换分析方式；侧栏菜单可直接进入统计、日志和策略，数据范围单独选择。

界面保留原版蓝白管理台的侧栏、统计卡片和记录表格，只小幅调整颜色、间距与标识。需要展示多条案例记录时，在“安全总览”点击“加载演示记录”，页面会显示简短的“演示数据”标签；这些虚构记录由本地检查实际生成，没有付费模型调用、消息拦截或管理员推送。截图不能去掉演示标记后当作真实防护事件提交。

## 可以使用的完成说明

> 目前已完成反诈与钓鱼信息检测系统的本机网页原型。用户可输入短信、邮件或聊天内容，系统进行本地规则检查、网址静态特征分析和带公开来源的知识检索。DeepSeek Agent 能在受控范围内选择只读工具，并生成包含原文依据、风险提示、待核实事项和建议步骤的结构化报告。程序支持报告导出、API 异常处理及自动化测试。当前尚未实现实时网站信誉查询、向量检索和手机端。结果仅供辅助核实，存在误报、漏报风险。

上述描述应在你亲自运行、理解并核对功能后使用。

## 老师可能会问

- **为什么是 Agent？** 模型可选择白名单工具，程序执行并回传结果，再生成报告；不是只调用一次 Prompt。若当次没有模型工具调用，日志会如实标记系统行为。
- **RAG 是怎么做的？** 当前为本地词法检索增强生成，使用关键词和 BM25 风格排序；尚未做 Embedding / 向量数据库。
- **如何避免胡编？** 检查输出结构、引用是否真的检索到、证据是否在原文中；这不能保证语义正确，仍需人工核实。
- **网址是否真的检查安全？** 只分析字符串结构，没有访问页面、查询信誉、检测恶意软件或验证发送者身份。
- **为什么正常通知不会保证不误报？** 当前是小型规则和模型原型，否定句只做有限处理，真实语言和诈骗变化复杂，需要更大的独立测试集。
- **密钥在哪里？** 从用户授权的操作系统环境读取，不写入代码或模型消息。不要在截图中展示实际值。
